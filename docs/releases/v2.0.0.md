## Highlights

- **Pure C11 + Direct2D / DirectComposition Rewrite (~1.2 MB, Zero WebView2)** — replaced Go/Wails/WebView2 with a standalone native C11 core and Direct3D 11 + DirectComposition + Direct2D 1.1 UI (`CLSID_D2D1GaussianBlur` glass menus/modals, DirectWrite typography, SQLite 3 amalgamation, `WH_KEYBOARD_LL` ring buffer hook).
- **Borderless Surface Rendering** — added `WS_EX_NOREDIRECTIONBITMAP`, explicit DWM border suppression (`DWMWA_BORDER_COLOR = DWMWA_COLOR_NONE`, `DWMSBT_NONE`, zero frame margins), `WM_NCCALCSIZE = 0`, `WM_NCPAINT = 0`, `SWP_FRAMECHANGED`, and immediate `Present(0, 0)` presentation so dragging window edges produces zero outer white/grey outline lag.
- **Continuous Cumulative Recording** — removed calendar date-range pickers and day cutoffs; keystrokes and per-app counts accumulate continuously while running, with direct database-wide rollup queries.
- **5 Built-in Color Schemes** — added Indigo (`indigo`), Ocean (`ocean`), Emerald (`emerald`), Amber (`amber`), and Rose (`rose`) palettes with live swatch previews in Settings alongside Dark / Light / Auto transitions.
- **Window Geometry Persistence (4:3 Ready)** — lowered `KS_MIN_WINDOW_WIDTH` / `KS_MIN_WINDOW_HEIGHT` to `780x540` and persisted DPI-aware window size and monitor-clamped position (`WINDOW_X`, `WINDOW_Y`, `WINDOW_WIDTH`, `WINDOW_HEIGHT`) across restarts.
- **Enhanced System Tray & Safe Stats Reset** — added Pause/Resume Recording, checkmarked Launch on Startup toggle, and Reset Layout & Settings (preserving all SQLite statistics) to the tray menu; removed reset from the top-right `⋮` menu and moved Clear Statistics into Settings behind a two-step red confirmation dialog.
- **Centered Emoji-Free Typography** — removed all emojis, centered labels vertically across keycaps, pills, modals, and list rows, and centered the status dot + label cleanly inside the top-right Live/Paused pill.

## Build

Download `key-stats.exe` (~1.2 MB, zero runtime dependencies) and run. Configuration and database are stored at `%APPDATA%/key-stats/` (or next to the executable when `.env` is placed alongside it without `PORTABLE_MODE=false`).
